# Commerce & Order Management Suite for Twenty CRM

The official Commerce extension for Twenty CRM, providing complete Product, Service, and Order Management capabilities.

## Features

- **Product & Service Catalog**:
  - Manage SKUs, pricing, stock quantities, images, and descriptions.
  - Distinguish between physical **Products**, **Services** (with duration in minutes for Spa/Clinic/Consulting), and **Service Packages**.
- **Order Management**:
  - Track orders with auto-generated order codes, customer relations, multiple line items, discounts, remaining debt, and sources.
- **Workflow & Calculations**:
  - Automatically compute order totals and remaining balance via Logic Functions.
  - REST endpoint `/commerce/orders` to create orders from external channels (Webcake, Pos, Shopify, WooCommerce).
